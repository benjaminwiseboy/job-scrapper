Bien démarrer

Veille Emploi cherche les offres pour toi sur plusieurs sites, les classe selon ton profil et rédige un CV adapté à chaque annonce qui compte.

Ce dashboard, c'est la vue

Il est toujours en ligne, sur ordinateur comme sur téléphone. Tu y tries les offres et suis tes candidatures. Il se met à jour tout seul pendant qu'une commande tourne.

Claude Code, c'est le moteur

Les commandes /veille:… se lancent dans Claude Code, sur ton ordinateur : scraping, classement, CV. Rien ne tourne en arrière-plan, tout part d'une commande.

Le cycle d'une recherche

  1. Configurer /veille:demarrer

    Une fois, au début. Ton CV ou ton export LinkedIn pré-remplit le profil, puis tu choisis les contrats (stage, alternance, CDI…) et les métiers visés. Chaque métier devient une recherche.

  2. Collecter /veille:scrape

    Tous les deux ou trois jours. Chaque passage interroge LinkedIn, Indeed, Hellowork, Météojob et l'APEC depuis le précédent, retire les doublons et classe les nouveautés.

  3. Trier, ici

    L'onglet Cibles ne montre que les offres qui collent à ton profil, les plus récentes en tête ; les autres attendent dans « Autres offres ». La tuile « Dernier refresh » compte ce que le dernier scraping a apporté. « Postulé » garde la trace de ta candidature, « Écarter » fait disparaître l'offre pour de bon, même aux passages suivants.

  4. Postuler, ici

    Le bouton « Candidater » d'une offre (ou l'onglet du même nom) : colle le texte de l'annonce, réponds à quelques questions, et Claude rédige le CV, la lettre et le mail à partir de ton profil, sans rien inventer. Les PDF se téléchargent directement et restent dans l'onglet CV. Même chose depuis Claude Code avec /veille:cv ACH-042.

  5. Suivre les réponses /veille:mail

    Lit ta boîte Gmail en lecture seule et met à jour les statuts : candidature reçue, entretien, refus.

  6. Affiner /veille:profil

    Un entretien guidé qui détaille tes expériences au format STAR : situation, tâche, action, résultat chiffré. C'est ce qui rend le classement juste et les CV percutants.

Lire une offre

Cible
Bon métier, niveau accessible, lieu et contrat qui te conviennent. À traiter en premier : elles ont leur propre onglet.
Possible
Correspondance partielle : bon métier mais contrat ou lieu imparfait, ou métier voisin. Dans l'onglet Autres offres.
Hors cible
Autre métier ou niveau hors de portée. Gardée un temps dans Autres offres, puis purgée. Les « alternances » publiées par des écoles pour recruter des étudiants sont écartées dès le scraping.
ACH-042
La référence à donner à /veille:cv.
~ 12 sept
Le tilde signale une date approximative : le site affichait « il y a 3 jours ».

Sous chaque offre, une phrase dit ce qui correspond à ton profil et ce qui manque. Dans chaque catégorie, les offres les plus récentes viennent en premier. À chaque scraping, les offres LinkedIn et Hellowork déjà en base sont revérifiées : celles qui n'acceptent plus de candidatures disparaissent de la liste (le filtre « Tout » les montre encore, marquées « Fermée »).

Toutes les commandes

/veille:demarrer
Onboarding : installation, profil, objectifs, premier scraping. Aussi pour créer un nouveau profil
/veille:scrape
Interroge les sources, classe les nouvelles offres, purge les anciennes
/veille:cv <ref>
Génère un CV adapté à une offre, à partir de sa référence
/veille:profil
Entretien guidé pour compléter ou corriger le profil et les recherches
/veille:mail
Met à jour les statuts depuis ta boîte mail : confirmations, entretiens, refus
/veille:events
Cherche salons, forums et job datings liés à tes recherches
/veille:profils
Liste tes profils, change de profil actif, met à jour le dashboard
/veille:source <url>
Teste si un site d'offres est scrapable, ou répare une source muette
/veille:purge
Nettoie les offres anciennes non retenues

Questions fréquentes

Le scraping ne ramène rien de nouveau

Chaque passage repart du précédent : si tu relances le même jour, c'est normal. Si une source reste vide plusieurs fois, l'onglet Paramètres la marque d'un point ambre ; /veille:source en trouve la cause, souvent un site qui a changé sa mise en page.

Où sont mes CV ?

Ceux rédigés dans l'onglet Candidater sont gardés dans le dashboard : l'onglet CV les retélécharge en PDF à tout moment. Ceux faits avec Claude Code sont sur ton ordinateur, dans le dossier de travail du profil (par défaut Documents/Veille-Emploi/<profil>/cv) ; l'onglet CV affiche le chemin exact.

Le bouton « Rafraîchir les offres » ne lance rien

Le scraping tourne dans Claude Code, sur ton ordinateur. Le bouton envoie la demande à une session Claude Code ouverte qui suit ce dashboard ; s'il n'y en a pas, il copie /veille:scrape pour que tu le colles dans Claude Code.

Qui paie la rédaction dans l'onglet Candidater ?

Elle passe par ton compte Claude, comme une conversation : la première fois, claude.ai te demande l'autorisation.

Qui peut voir ce dashboard ?

Toi seul, tant que tu ne le partages pas. Il contient ton profil complet : partage-le en connaissance de cause.

Je cherche un stage et un CDI, ou j'aide quelqu'un d'autre

Deux métiers différents tiennent dans un même profil, sous forme de deux recherches. Pour séparer complètement deux projets, crée un second profil avec /veille:demarrer : il aura son propre dashboard. /veille:profils passe de l'un à l'autre.

J'ai changé d'ordinateur

Tes dashboards et leurs données restent sur ton compte Claude. Réinstalle le plugin, puis lance /veille:profils pour les rebrancher.

Pourquoi pas de scraping automatique ?

Le scraping a besoin de ton ordinateur allumé, avec Claude Code ouvert. Le lancer à la main quand tu t'assois pour chercher évite de consommer pour rien et de solliciter les sites sans raison.

Installer sur un autre poste

Dans un terminal, avec Claude Code et Node.js déjà installés :

claude plugin marketplace add benjaminwiseboy/job-scrapper
claude plugin install veille@veille-emploi

Autre option, avec le fichier veille-emploi.zip : le dézipper, puis double-cliquer sur Installer.cmd (Windows) ou Installer.command (Mac). Il installe Node.js s'il manque, après avoir demandé.

Ouvre ensuite Claude Code et tape /veille:demarrer.
